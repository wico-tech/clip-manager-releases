# Clip Manager downloads

Installers for **Clip Manager**, a Windows app that finds the best moments in a long video and turns
them into vertical clips for TikTok, Reels and Shorts. This repository holds only the installers;
installed copies also check it for updates.

## Download

Get `ClipManager-Setup-<version>.exe` from the [latest release](../../releases/latest).

- Windows 10 or 11, 64-bit
- About 1.3 GB of free disk space
- A free Google Gemini API key (the app shows where to get one)

## Installing

The installer isn't code-signed yet, so Windows may show **"Windows protected your PC"**. Click
**More info**, then **Run anyway**. The app installs for your Windows account only and doesn't ask
for administrator rights.

## Trial and license

The first 7 days are the full version. After that, the free version renders up to 3 clips at a time
with a "Made with Clip Manager" watermark, until you activate a license key in Settings.

## Updates

Installed copies check here when they start and every few hours, download new versions in the
background and install them when you close the app. What changed is in each release's notes.
